# Contributing to DemoPages

## Welcome

Thanks for your interest in DemoPages! Contributions are welcome. This is a small static demo site, so changes are simple to make and review.

## Getting started

1. Fork the repository.
2. Clone your fork:

    ```bash
    git clone https://github.com/<your-username>/DemoPages.git
    ```

3. Open `index.html` in a browser to preview your changes. No build step is needed.

## Making changes

Create a branch for your work, for example `feature/<short-description>` or `fix/<short-description>`:

```bash
git checkout -b feature/<short-description>
```

Keep commits small and write clear commit messages.

## Code style

- Write valid, indented HTML.
- Use 4-space indentation (no tabs), matching `index.html`.

## Submitting a pull request

1. Push your branch to your fork.
2. Open a pull request against `main`.
3. Describe what changed and why.
4. Link any related issue, for example `Closes #123`.

## Reporting issues

Open an issue with a clear description of the problem and the steps to reproduce it.
